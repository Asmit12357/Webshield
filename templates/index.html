What gets checked

HTTPS and certificate
Whether the site is served over HTTPS, the certificate is trusted and not about to expire, and plain HTTP redirects to HTTPS.
Browser security headers
HSTS, Content-Security-Policy, clickjacking protection, MIME sniffing and Referrer-Policy. The value is graded, not just whether the header exists.
Cookies
Whether session cookies set during the visit, including during redirects, carry the Secure, HttpOnly and SameSite flags.
Information leaks
Server and framework version numbers in headers, and insecure resources loaded on an HTTPS page.
